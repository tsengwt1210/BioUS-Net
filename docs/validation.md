## 像素準確率與版本對應

五折訓練會取出每折 `info.ValidationAccuracy` 最後一個非 NaN 值，再計算平均值與標準差。這個數值對應像素分類準確率；不能轉寫為 Dice、IoU 或獨立測試成績。背景占比較高時，也應搭配目標類別的分割指標判讀。

目前公開檔案沒有保存與每個 Git 版本一一對應的資料分組、環境清單及完整評估結果，所以 README 不把既有專題報告中的數字當成目前 Attention 版本的實測成績。

## 會影響重現的程式行為

1. **分組未隨模型儲存。** 80/20 訓練直接使用 `randperm`；批次分析中的「訓練集／驗證集」會重設亂數後重新切分，不能保證與模型訓練時相同。五折模型也不能套用這個重新產生的 80/20 分組當作各折驗證集。
2. **資料以影像為單位切分。** 程式沒有依測試片、實驗批次或拍攝來源分組。若影像之間存在相關性，正式評估需另設分組策略，避免相近樣本跨越訓練與驗證集。
3. **訓練模式的設定不同。** 主程式 80/20 模式加入平移與色彩擾動，五折模式未使用這兩項；80/20 也未明訂最大 epoch。詳細設定見 [版本比較](versions.md)。
4. **後處理改變面積。** 閉運算、填洞與凸包修補可能合併區域或填入凹區；需保留原始分割與後處理結果，才便於分析面積誤差。
5. **預設尺度未經此套件校正。** 每像素面積、最小區域與形態學半徑都是可調參數。它們不是可直接套用到其他倍率或拍攝條件的常數。
